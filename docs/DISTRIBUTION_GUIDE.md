# 赠予版分发指南

本文档说明如何构建、打包和分发赠予版给用户。

---

## 📦 分发包结构

用户收到的压缩包包含：

```
Observer-赠予版-UserName-20241101.zip
├── Observer-Of-STZB.exe          # 主程序（已授权）
├── windows-user-guide.md         # 详细使用手册
└── 使用必读.txt                   # 快速开始指南
```

---

## 🚀 快速分发流程

### 方式一：自动化构建和打包（推荐）

```bash
# 一键构建和打包
./packaging/scripts/build_and_pack.sh "123.456.789.012" "Friend1" "2027-04-30"
```

**参数说明**：
- 第1个参数：用户的IP地址
- 第2个参数：用户名称（用于文件命名）
- 第3个参数：过期日期（YYYY-MM-DD格式）

**输出**：
- `releases/Observer-赠予版-Friend1-20241101.zip`

### 方式二：手动分步操作

#### 步骤1：构建授权版本

```bash
python packaging/scripts/build_beta.py \
  --ip "123.456.789.012" \
  --expiry "2027-04-30" \
  --output "Observer-赠予版-Friend1.exe"
```

#### 步骤2：打包压缩包

```bash
python packaging/scripts/pack_release.py \
  --exe "dist/Observer-赠予版-Friend1.exe" \
  --user "Friend1"
```

## 📋 分发前检查清单

在将压缩包发送给用户之前，请确认：

- [ ] 已设置正确的用户IP
- [ ] 已设置合适的过期日期（通常3-6个月）
- [ ] exe文件名包含用户标识（便于管理）
- [ ] 压缩包包含所有必需文件（exe + 使用手册 + README）
- [ ] 已在自己的机器上测试验证通过

## 🎯 不同用户场景

### 场景1：熟人/信任用户

**特点**：
- 可以提供较长的授权期限
- 使用宽松验证模式
- 沟通更直接

**构建命令**：
```bash
./build_and_pack.sh "123.456.789.012" "Friend1" "2027-12-31"
```

**发送消息**：使用简洁版模板

### 场景2：测试用户/陌生人

**特点**：
- 较短的授权期限（3个月）
- 可以使用严格模式（提前收集设备信息）
- 需要更详细的说明

**构建命令**：
```bash
# 方式1：首次自动绑定设备
./build_and_pack.sh "123.456.789.012" "Tester1" "2027-04-30"

# 方式2：严格模式（需提前收集设备指纹）
python packaging/scripts/build_beta.py \
  --ip "123.456.789.012" \
  --device "abc123def456..." \
  --strict \
  --expiry "2027-04-30" \
  --output "Observer-赠予版-Tester1.exe"

python packaging/scripts/pack_release.py \
  --exe "dist/Observer-赠予版-Tester1.exe" \
  --user "Tester1"
```

**发送消息**：使用详细版模板

### 场景3：IP不固定的用户

**特点**：
- 用户使用移动网络或IP经常变化
- 仅依赖设备绑定

**构建命令**：
```bash
python packaging/scripts/build_beta.py \
  --ip "0.0.0.0" \
  --no-ip-check \
  --expiry "2027-04-30" \
  --output "Observer-赠予版-Mobile1.exe"

./pack_release.sh "dist/Observer-赠予版-Mobile1.exe" "Mobile1"
```

## 🔧 常见分发问题

### Q1: 用户反馈IP验证失败

**原因**：用户的IP地址变了（特别是重启路由器后）

**解决方案**：
1. 询问用户当前IP
2. 重新构建包含多个IP的版本
3. 或者禁用IP验证（仅设备绑定）

### Q2: 用户要在多台电脑使用

**处理方式**：
- 不建议：赠予版设计为单设备绑定
- 如果确实需要：为每台设备单独构建一个版本
- 或者：构建时添加多个设备指纹

### Q3: 用户需要延长授权期限

**处理方式**：
1. 重新构建新的授权版本
2. 更新过期日期
3. 发送新的压缩包给用户
4. 用户删除旧版本，使用新版本

### Q4: 压缩包太大

**优化方式**：
- 检查是否包含了不必要的文件
- 使用更高的压缩率
- 正常情况下压缩包大小应该在 30-50 MB

## 📝 分发后跟进

### 建议的跟进流程

**第1天**：发送压缩包和使用说明

**第2-3天**：询问是否成功安装和运行
```
安装顺利吗？有遇到什么问题吗？
```

**第7天**：确认使用体验
```
使用一周了，感觉怎么样？
有什么功能需求或改进建议吗？
```

**过期前7天**：提醒即将过期
```
你的授权将在 X 天后到期。
如需继续使用，请告知我。
```

### 收集反馈

重点关注：
- ✅ 安装过程是否顺利？
- ✅ 功能是否符合需求？
- ✅ 有哪些改进建议？
- ✅ 是否遇到技术问题？
