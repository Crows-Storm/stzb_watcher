## 🚀 快速开始

### 第一步：安装 Npcap

Npcap 是网络数据包捕获工具，Observer 需要它来监测游戏数据。

#### 如何安装 Npcap：

1. **下载 Npcap 安装包**
   - 打开浏览器，搜索 `Npcap 下载`
   - 或访问 Npcap 官方网站下载最新版本
   - 下载后会得到 `npcap-x.xx.exe` 文件

2. **运行 Npcap 安装程序**
   - 右键点击 `npcap-x.xx.exe`
   - 选择 **"以管理员身份运行"**
   - 点击 "I Agree" 同意协议

3. **安装选项（重要！）**
   - ✅ 勾选 **"Install Npcap in WinPcap API-compatible Mode"**
   - ✅ 勾选 **"Support loopback traffic"**（如有此选项）
   - 点击 "Install" 开始安装

4. **完成安装**
   - 等待安装完成
   - 点击 "Finish"
   - **重启电脑**（推荐，确保驱动加载）

#### 如何确认 Npcap 已安装：

- 方式1：查看 `C:\Windows\System32\Npcap\` 文件夹是否存在
- 方式2：在设备管理器中查看是否有 "Npcap Loopback Adapter"

---

### 第二步：解压程序

1. 找到下载的 `Observer-赠予版.zip` 文件
2. 右键点击，选择 **"解压到当前文件夹"** 或 **"解压到 Observer-赠予版\"**
3. 解压到一个**不含中文路径**的位置（推荐：`D:\Observer\`）

**❌ 错误示例**：`C:\用户\张三\桌面\Observer\`（包含中文）  
**✅ 正确示例**：`D:\Observer\` 或 `C:\Programs\Observer\`

1. 打开安全软件

## 🎮 使用 Observer

### 访问 Observer 界面

程序启动后：

1. 浏览器会自动打开 `http://127.0.0.1:8080`
2. 如果浏览器没有自动打开，请手动在浏览器地址栏输入：`127.0.0.1:8080`

### 开始抓取游戏数据

#### 方式一：使用内置抓包功能（推荐）

1. 打开 Observer Web 界面
2. 点击 **"设置"** 或 **"工具"** 菜单
3. 点击 **"启动抓包"**
4. 打开《率土之滨》游戏
5. 在游戏中进行操作（打开地图、查看战报等）
6. 返回 Observer，刷新页面查看数据

#### 方式二：手动配置网络代理

如果内置抓包不工作，可以使用手动配置：

1. 查看 Observer 启动窗口，记下代理端口（通常是 8080）
2. 配置系统代理或游戏代理指向 `127.0.0.1:8080`
3. 打开游戏，进行操作
4. 数据会自动被 Observer 捕获

### 关闭程序

- **不要直接关闭命令行窗口！**
- 正确方式：
  1. 在命令行窗口中按 `Ctrl + C`
  2. 或者直接关闭浏览器，然后关闭命令行窗口

## 🔧 常见问题

### Q1: 程序启动后立即关闭或报错

**可能原因**：
- 没有安装 Npcap
- 没有使用管理员权限运行
- 端口 8080 被其他程序占用

**解决方法**：
1. 确认已安装 Npcap（查看第一步）
2. 右键选择 **"以管理员身份运行"**
3. 关闭占用 8080 端口的其他程序（如其他 Web 服务器）

### Q2: 浏览器无法打开或显示"无法访问此网站"

**解决方法**：
1. 确认命令行窗口仍在运行（不要关闭）
2. 手动输入地址：`http://127.0.0.1:8080`
3. 尝试使用其他浏览器（Chrome、Edge、Firefox）
4. 检查防火墙是否拦截了本地连接

### Q3: 授权验证失败

**可能显示**：
```
❌ 授权验证失败
未授权的IP地址或设备
```

**原因**：
- 您的网络 IP 地址发生了变化
- 在未授权的设备上运行

**解决方法**：
- 联系开发者更新授权信息
- Telegram: @sander678

### Q4: 页面没有数据

**解决方法**：
1. 确认已启动抓包功能
2. 打开游戏，进行一些操作：
   - 打开大地图
   - 查看战报
   - 查看同盟信息
3. 返回 Observer，刷新页面
4. 如果仍然没有数据，重启程序并重新抓包

### Q5: 安全软件报毒或拦截

**这是误报！** Observer 是安全的，但某些安全软件会误判。

**解决方法**：
1. 将 `Observer-Of-STZB.exe` 添加到安全软件的白名单
2. 或者临时关闭安全软件的实时防护
3. 如果使用 Windows Defender：
   - 打开 "Windows 安全中心"
   - 点击 "病毒和威胁防护"
   - 点击 "病毒和威胁防护设置"
   - 添加排除项，选择 Observer 的文件夹

### Q6: 提示"授权期已结束"

您的授权已到期。如需继续使用，请联系开发者：

- Telegram: @sander678

### Q7: 端口被占用怎么办？

如果提示端口 8080 已被占用：

**方法1：关闭占用端口的程序**
1. 打开任务管理器（Ctrl + Shift + Esc）
2. 找到占用 8080 端口的程序
3. 结束该程序

**方法2：使用其他端口启动**（高级用户）
```
Observer-Of-STZB.exe --port 8081
```
然后访问 `http://127.0.0.1:8081`

## 💡 使用技巧

### 技巧1：创建桌面快捷方式

1. 右键点击 `Observer-Of-STZB.exe`
2. 选择 **"发送到"** → **"桌面快捷方式"**
3. 右键点击桌面上的快捷方式，选择 **"属性"**
4. 点击 **"高级"** 按钮
5. 勾选 **"以管理员身份运行"**
6. 点击 "确定" 保存

以后双击桌面快捷方式即可直接以管理员身份启动。

### 技巧2：保持程序窗口运行

- 程序启动后的黑色命令行窗口**不要关闭**
- 可以将其最小化到任务栏
- 只要窗口在运行，Web 界面就可以正常访问

### 技巧3：多开游戏账号

Observer 支持同时监测多个游戏账号：
1. 保持 Observer 运行
2. 登录不同账号
3. 数据会自动区分和存储

### 技巧4：数据导出

Observer 支持导出数据：
1. 在 Web 界面中找到需要的数据
2. 通常有 "导出" 或 "下载" 按钮
3. 可以导出为 CSV、JSON 等格式
